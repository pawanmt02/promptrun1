# Contributing to PAISA.OS

Thank you for your interest in contributing to **PAISA.OS**!

## Development Workflow
1. **Prerequisites**: Node.js v18+ and npm installed.
2. **Setup**:
   ```bash
   git clone https://github.com/pawanmt02/PromptRun.git
   cd PromptRun
   npm install
   ```
3. **Run Dev Server**:
   ```bash
   npm run dev
   ```
4. **Code Quality Standards**:
   - Run `npm test` to verify all automated test suites pass.
   - Run `npm run lint` to ensure zero linter warnings or errors.
   - Run `npm run build` to ensure clean TypeScript compilation and optimized bundle generation.
